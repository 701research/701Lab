# setup

This directory contains setup-related documentation for the 701Lab project.

The primary document currently provided here is:

- [rpi-node-setup.md](./rpi-node-setup.md)  
  A setup and configuration summary for the Raspberry Pi measurement node used in 701Lab.

It covers the main hardware-related setup outline, interface assignments, OS and Python environment, `config.txt` settings, device recognition checks, data storage structure, and switch / LED UI design.

For the wiring details of the Raspberry Pi sensor node, please also refer to the hardware-side wiring diagram:

- [RasPi_Sensor_Wiring_Diagram.pdf](../hardware/RasPi_Sensor_Wiring_Diagram.pdf)

Additional setup documents may be added here in the future as the repository structure is further developed.
