# 701Lab

701Lab は、オートバイのライドセンシング、マルチセンサーデータロギング、解析、可視化のためのオープンな技術基盤です。

本リポジトリは、701Lab プロジェクトで構築してきたハードウェア構成、セットアップ手順、データ取得プログラム、解析ツール、可視化パイプラインを、他者が理解し、再利用し、拡張できる形に整理したものです。

このリポジトリの目的は、単にファイルを置くことではなく、701Lab の技術ワークフローを

- 他者にとって理解しやすく、
- 必要に応じて再現可能で、
- 将来的な拡張や改良がしやすい

形にすることにあります。

---

## 概要

701Lab は、以下のワークフローを軸として発展してきました。

1. Raspberry Pi ベースの計測ノードを構築する  
2. 複数センサーのデータを取得し、run ベースの統合ログとして記録する  
3. Raspberry Pi 側で軽量な計測後処理を行う  
4. Windows 側で run 横断およびセンサー単位の解析を行う  
5. HUD ベースの可視化を含む映像出力を生成する  

本リポジトリは、このワークフローのうち公開可能な部分を、構造化された公開基盤として提供することを目的としています。

## このリポジトリが役立つかもしれない人

このリポジトリは、たとえば以下のような関心を持つ人に役立つ可能性があります。

- Raspberry Pi ベースの計測システムやロギングシステムを構築したい人  
- マルチセンサー取得ワークフローを整理したい人  
- 後段解析のための run ベースデータ構造を設計したい人  
- 軽量なエッジ側処理と、より豊富なホスト側解析を分離して設計したい人  
- 実験・センシングプロジェクトを再利用可能な技術基盤として構造化する方法を学びたい人  

また、センシング、ロギング、実験データパイプラインに取り組む学生、研究者、開発者にとっても、実践的な参考例となることを意図しています。
